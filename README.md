# Everest (Archipelago with Physical Item Integration)

[![Everest Fork](https://img.shields.io/badge/Fork-Everest-blue.svg)](https://github.com/TheGabenZoned/Everest)
[![Archipelago](https://img.shields.io/badge/Archipelago-Core-green.svg)](https://archipelago.gg)

**Everest** is a fork of [Archipelago](https://archipelago.gg) that introduces **true cross-game physical item integration**. Instead of seeing generic tokens or text placeholders when finding foreign game items in a multiworld, players see their character physically discover, hold, and interact with the authentic 3D models, sprites, and animations from the other game!

For example:
* **In Ocarina of Time**: Finding an item belonging to Super Mario 64 renders the actual **3D Mario 64 Power Star** (or 1-Up Mushroom / Bowser Key) inside the chest or shop, complete with Link lifting it above his head in full two-hand triumph animation and custom textboxes!
* **In Super Mario 64**: Finding an item belonging to Ocarina of Time spawns Link's **3D Kokiri Sword, Master Sword, Hylian Shield, or Megaton Hammer** rotating and shining in the level for Mario to physically grab with fanfare!
